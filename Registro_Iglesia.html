🔗 Conexión con Google Sheets

Ingresa la URL de tu Google Apps Script para que cada registro se envíe automáticamente a tu hoja de cálculo.

ℹ️ Instrucciones
  1. Crea un Google Sheet con los encabezados correctos en la fila 1
  2. Ve a Extensiones → Apps Script y pega el código del script
  3. Implementa como Aplicación web con acceso para cualquier persona
  4. Copia la URL generada y pégala arriba
  5. Cada registro que guardes se enviará automáticamente
🗑️ Datos locales

Los registros también se guardan localmente en este navegador como respaldo.
